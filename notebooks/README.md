## このページの見方

- 数値は、各Notebookを**実行したときの出力**です。乱数のシードを固定しているので、**同じ数値になります**（環境やライブラリのバージョンで、小数点以下が少しずれることはあります）。
- 特に断りがなければ、**世界（データ）を変えた10回の平均**です。`標準誤差`は**平均のぶれ**で、**手法の差が標準誤差の2倍より小さいときは、差があるとは言えません**。
- 評価は**2種類**あります。**観測テスト**（偏った観測の中で、実際に高く評価されたものを当てられたか）と、**本当の好み**（合成データだけが知っている答えで、好きなものを当てられたか）。**この2つは、一致しないことがあります**。
- 順位の指標は、上位10件で測ります（precision@10・NDCG@10）。
- 詳しい考察は [../MANUAL.md](../MANUAL.md)、最終レポートは [../REPORT.md](../REPORT.md) にあります。

## 用語集

| 用語 | やさしい説明 |
|---|---|
| **precision@10** | 薦めた上位10件のうち、好きなものの割合 |
| **NDCG@10** | 好きなものが上位にあるほど高い指標（0〜1） |
| **カバレッジ** | 薦められた商品の種類の割合。低いと、全員に同じ少数を薦めている |
| **露出のジニ係数** | 薦める回数の偏り（0=均等、1=1つに集中） |
| **人気順** | 評価の多い順に薦める。強い基準 |
| **平均評価順** | 商品の平均評価の高い順（全員に同じ。個人化なし） |
| **近傍法** | 似た商品（ユーザー）の評価から薦める |
| **行列分解（ALS／BPR）** | ユーザーと商品を少数の潜在因子で表す。ALSは点数を当て、BPRは順位を学ぶ |
| **コールドスタート** | 評価が無い（少ない）新しい商品・ユーザーに薦める問題 |
| **逆確率重み付け（IPS／IPW）** | 観測される確率の逆数で重みを付ける補正 |
| **MNAR** | 観測されるかどうかが、好み自体に依存すること |
| **フィードバックループ** | 薦めたものがよく評価され、次の学習データになり、また薦められる循環 |

## 00 データと基準 — 観測テストと本当の好みで、順位が逆転する

合成データ（1000ユーザー・500商品・評価2.5万件）を作り、基準を比べます。

| 基準 | 観測テスト（precision@10） | 本当の好み | カバレッジ |
|---|---|---|---|
| ランダム | 0.0075 | 0.262 | 1.00 |
| 人気順 | **0.0743** | 0.352 | 0.06 |
| 平均評価順 | 0.0203 | 0.653 | 0.04 |
| 上限（本当の好みで薦める） | 0.0227 | **0.972** | 0.81 |

- **観測テストでは、人気順が上限を上回ります**。観測が人気に偏って作られるため、人気のものを薦めれば観測と一致しやすい。
- **本当の好みでは逆転**します。人気順は全員にほぼ同じ少数の商品を薦めます（カバレッジ0.06）。

## 01 評価の落とし穴

- **RMSEと順位は別物**: ユーザーの平均で評価点を予測するとRMSEは約8%改善しますが、全商品に同じ点なので順位は変わりません。RMSE最良のバイアスモデルも、観測NDCGは人気順の4分の1。
- **候補の選び方で数字が変わる**: 正解＋ランダム100個を候補にする評価では、ランダムでも約4倍の数字が出ます。人気順÷上限の比は 4.1倍→2.2倍→1.2倍と縮む。**評価方法を明記し、別の方法の数字を比べない**。
- **偏りが強いほど、観測の順位は本当とずれる**: 順位相関は、偏りなし0.92、標準0.67、強い偏り0.58。
- 世界10回の本当のprecision: 上限0.973 ＞ バイアス0.618 ≒ 平均評価順0.616 ＞ 人気順0.305 ＞ ランダム0.230。

## 02 近傍法

| 手法 | 観測NDCG | 本当のprecision | カバレッジ |
|---|---|---|---|
| 人気順 | 0.168 | 0.305 | 0.07 |
| 平均評価順 | 0.040 | **0.616** | 0.04 |
| アイテム型・評価した | 0.166 | 0.321 | 0.23 |
| アイテム型・好き | 0.180 | 0.495 | 0.71 |
| ユーザー型・好き | 0.186 | 0.472 | 0.61 |

- **入力が、学ぶものを決めます**。「評価した」（0/1）は露出を学び、人気順と同じ。「好き」にすると本当の好みの当たりが上がります。
- **個人化のない平均評価順（0.616）に及びません**。疎なデータでは、個人化は簡単には効かない。
- **観測テストでハイパーパラメータを選ぶと、本当の好みが約0.03下がります**（人気を強く効かせる設定に偏る）。

## 03 行列分解 — 評価の点数を使うと、個人化が効く

| 手法 | 観測NDCG | 本当のprecision | カバレッジ |
|---|---|---|---|
| 人気順 | 0.168 | 0.305 | 0.07 |
| 近傍法（アイテム型・好き） | 0.180 | 0.495 | 0.71 |
| **ALS（k=4）** | 0.109 | **0.798**（±0.010） | 0.23 |
| BPR（外し役：一様） | 0.160 | 0.473 | 0.41 |
| BPR（外し役：人気に比例） | 0.054 | 0.519 | 0.72 |

- ALSは**観測NDCGでは人気順より低い**のに、本当の好みでは圧倒的。観測テストだけで評価すると見落とします。
- **BPR**は、外し役を一様に選ぶと露出（人気）を学び、人気に比例して選ぶと偏りが弱まります。
- **データが増えるほど個人化が効きます**（1人あたり10件→100件で、ALSの本当のprecisionは 0.682→0.894。学習した因子と真の因子の重なり 0.21→0.88）。
- 正則化が弱いと過学習（RMSE 1.04）、強すぎると因子が使われない。

## 04 コールドスタート

| 新しい商品（評価0件） | 本当のprecision |
|---|---|
| ランダム／人気順／平均評価順／ALS | 0.243〜0.244（**どれも同じ**） |
| ジャンル好み（コンテンツ） | 0.486 |
| ALS＋ジャンル事前分布（ハイブリッド） | 0.504 |
| 上限（ジャンルだけで分かる最良） | 0.631 |

- 評価が集まると、ハイブリッドとALSの差は **+0.261（0件）→+0.072（5件）→+0.031（50件）** と縮みます。
- 新しいユーザーは、評価が5〜10件で、ALS（フォールドイン）が平均評価順を +0.12〜+0.16 上回ります。
- **ジャンル札が不正確だと害になります**（評価5件・札が全部ランダムで −0.088）。

## 05 偏りの補正とフィードバックループ

- **商品ごとのIPSは、好みに依存する偏り（MNAR）を補正できません**。手法の並びの順位相関は、偏りが弱いと 0.27→0.45 に上がるが、標準以上では約0のまま。
- **IPW-ALS**は、全部の組のRMSEを良くします（0.740→0.720）が、上位10件の順位には効きません。重みが強すぎる（γ=1.0）と有害（0.720）。
- **推薦を8回繰り返す**と、人気順では偏りが増幅します（評価件数のジニ 0.563→0.727）。ALSではいったん上がって戻ります。
- **人気を抑える並べ替え**は、λ≤0.1ならprecisionはほぼ変わらず（0.791→0.789）、λ=0.2で0.583に崩れます。評価が少ないユーザーの不利（0.742対0.822）は、直りません。

## 最終評価（REPORT.md）

新しい世界10個で1回だけ評価した結果: 本当のprecision は ALS **0.856** ＞ 平均評価順 0.630 ＞ 近傍法 0.559 ＞ 人気順 0.324 ＞ ランダム 0.246。観測NDCGは近傍法 0.189・人気順 0.159・ALS 0.111 で、**観測と本当が逆転する**ことを確認しました。詳しくは [../REPORT.md](../REPORT.md)。
