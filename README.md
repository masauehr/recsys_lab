# recsys_lab

**推薦システム**（ユーザーに、好みそうなものを薦める）を、合成データで学ぶプロジェクト。
「何を薦めると喜ばれるか」を、**観測できるデータ（評価・クリック）**から予測する仕組みを、自分の手で作って確かめる。

詳しくは [MANUAL.md](MANUAL.md) / [DATA_SPEC.md](DATA_SPEC.md) / [EVALUATION.md](EVALUATION.md) / [PLAN.md](PLAN.md) を参照。

> 🔒 すべて**合成データ**（プログラムで作ったユーザーと商品）。実在の個人の閲覧・購入履歴は使わない。

## なぜこのプロジェクトか

[ai_core](../ai_core/PROJECT_MAP.md) で「未経験」だった分野の1つが**推薦**。
推薦は、分類や回帰と**似ているようで違う**。

- **欲しい答えは、順位**（上位10件に、好きなものが入るか）。**点数の予測の誤差（RMSE）が小さくても、順位が良いとは限らない。**
- **見えているデータは、偏っている**。人は、**人気のもの**や**すでに好きなもの**に触れやすい。触れなかったものは「嫌い」ではなく「**知らない**」。
- **薦めると、データが変わる**（薦められたものが、よく見られる）。偏りが**増幅**する。
- **新しいユーザー・商品**には、データがない（**コールドスタート**）。

合成データなら、**本当の好み（正解）**を持てるので、「観測データでの評価」と「本当の良さ」の**ずれ**を測れる。

## 進め方の方針

- **基準を先に作る**: ランダム、**人気順**（意外に強い）。学習の価値は、基準との比で測る。
- **手法を1つずつ足す**: 近傍法 → 行列分解 → コンテンツ併用 → 偏りへの対処。
- **評価を疑う**: 観測データでの順位指標（NDCG など）と、**本当の好み**での評価を、両方出す。
- **条件を1つだけ変える**。複数シードで見る。

## 作るもの

```
Phase0 合成データ生成器（本当の好み＋偏った観測）・評価指標・基準（ランダム／人気順）
 ─▶ Phase1 評価の落とし穴（RMSEと順位、人気順の強さ、観測データと本当の好みのずれ）
 ─▶ Phase2 近傍法（ユーザー型・アイテム型）
 ─▶ Phase3 行列分解（潜在因子）
 ─▶ Phase4 コールドスタートとコンテンツ併用
 ─▶ Phase5 偏り（人気・露出）と、薦めた結果の循環（フィードバックループ）
 ─▶ Phase6 最終評価・最終レポート
```
